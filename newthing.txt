The user provides a medical image, medical document, and an audio file. The medical document is first encrypted using AES-256, and the AES key is secured using RSA-2048 encryption. A binary noise mask used for adaptive steganographic embedding is generated and hidden inside the user-provided audio using audio steganography.

The duration of the audio file is used to calculate the total number of video frames at 30 FPS. A video is then generated in which every frame visually contains the steganographic medical image. The first frame is reserved as the metadata frame, which stores encrypted information about the remaining frames, including chunk mapping, payload structure, frame allocation, integrity hash, and extraction parameters.

The encrypted medical payload is divided into N chunks, where N equals the total number of frames minus one. These chunks are randomly distributed across the remaining video frames using adaptive multi-bit LSB steganography. During extraction, the receiver first retrieves the binary mask from the audio, then extracts metadata from the first frame, reconstructs the payload using the frame mapping information, verifies integrity using SHA-256, and finally decrypts the medical document using RSA and AES decryption.
